# Подборка точек для редактора

Контракт интерфейса, 24 октября 2026. Это локальная подборка публичных ссылок,
а не подписка, избранное профиля или передача влияния.

## Действия

В просмотре и квадратном меню сферы доступны «Скопировать ссылку» и
«Запомнить точку» / «Убрать из подборки». Копирование пишет обычный URL в
системный буфер только по нажатию. При отказе браузера появляется выделяемое
поле адреса. Приложение никогда не читает системный буфер автоматически.

Подборка переживает переходы и перезагрузку страницы в localStorage текущего
браузерного origin. Ключ разделён по origin сервера регистрации. Хранятся только
ID, короткое публичное название и URL, не версии текста, сессии или профиль.
В адресе сохраняются только p/open; лишние параметры и fragment отбрасываются.
Лимит —64 точки с устранением дублей. При запрете/переполнении хранилища остаётся
копия в памяти текущей страницы; интерфейс сообщает, что она не постоянная.
Разные независимые регистраторы не объединяют подборки.

## Редактор

Компактная секция над текстом позволяет отметить несколько точек, добавить
их как связи либо вставить смысловые Markdown-ссылки в текущую позицию текста.
Выделенные слова можно обернуть одной ссылкой. Для нескольких ссылок выделенный
текст сохраняется, ссылки вставляются после выделения. Связи не дублируются.
Максимум16 различных связей и8192 символа остаются серверными ограничениями.

Каждая выбранная точка заново читается через существующий public point API в
контексте сайта. Ошибка любого чтения не добавляет частичный набор и не меняет
текст. Скрытые/удалённые/изменившиеся точки не получают обхода существующей
проверки доступности и закрепления версии. Пока публикация неопределённа,
подборка не может менять закреплённый черновик.

Точку можно добавить адресом без поиска. Из URL извлекается только ID; читается
локальный public API. URL не скачивается: это не импорт внешнего сервера.
Подборка не очищается автоматически после публикации; убрать отдельные элементы
или очистить её можно явно. Само сохранение точки не изменяет граф.

## Overlay и внешняя статическая копия

Разные browser origins не получают общий localStorage. При открытии редактора
поверх карты родитель передаёт только подборку публичных ссылок. Используется
существующий протокол node06-editor/1 с точной проверкой origin, source и channel:

| Сообщение | Направление | Данные |
| --- | --- | --- |
| clipboard-request | редактор → карта | запрос текущей подборки |
| clipboard | карта → редактор | scope, до64 публичных refs, persistent |
| clipboard-remove | редактор → карта | до64 удаляемых ID |
| clipboard-add | редактор → карта | один проверенный публичный ref |

Получение списка не добавляет связи и не публикует текст. Даже поддельный ref
потребует отдельного пользовательского выбора и свежего публичного чтения.
Сессия/CSRF, пароли и приватные списки не передаются. Внешний редактор остаётся
анонимным; публикация требует прежнего отдельного подтверждения на доверенном
сервере. Открытая отдельно новая вкладка другого origin получает свою локальную
подборку; туда можно перенести обычные ссылки вручную.
