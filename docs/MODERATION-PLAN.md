# Модерация, подключение источников и синхронизация — решения владельца

Статус: согласовано 24 октября 2026, **не реализовано** этим пакетом.
Технические проверки ниже — условия будущей реализации, не выполненные обещания.

## Модерация

- Полномочия выдаются на конкретный сайт или сервер; можно делегировать доступ
  к другому участку. Модератор сайта скрывает/восстанавливает только там,
  серверный модератор — на всём сервере. Общая точка сохраняет видимость на других
  сайтах при локальном скрытии.
- Панель жалоб вместо потока сообщений. Один случай на точку и область,
  повторные жалобы увеличивают счётчик. Рекомендуется считать уникальных
  заявителей и делать повторы запросов идемпотентными.
- Только серверное скрытие запускает 30 суток непрерывного скрытия. Затем
  содержимое удаляется, ID и пустая отметка остаются. Восстановление до срока
  отменяет удаление. Локальное скрытие сайта не удаляет общие данные.
- Временные баны с длительностями: запрет создавать точки либо карантин новых
  точек. В карантине их видят **все забаненные** пользователи и модераторы/админы
  с полномочиями в соответствующей области. Возможно усиление до полного блока.
  Это не существующая личная блокировка автора и не отрицательное доверие.

Перед включением удаления нужны проверяемые правила для всех ревизий, поисковых
индексов, превью, событий и вложений; аудит и backup/restore. Git-обновление,
статический fallback, public API, bridge, neighbors, профиль и лента не должны
обходить скрытие. Чужие Git-копии, кэши и серверы нельзя считать удалёнными.
Скрытие в БД не переписывает исходный Git; правила повторного импорта должны
сохранять moderation tombstone. Конкретная модель таблиц/ролей и защита от гонок
определяются в реализации. Автоматического purge пока нет.

## Git и оформление

Прямое подключение нашего источника должно обновляться автоматически. Для
собственного репозитория/копии/форка режим обновления выбирает администратор.
Операторская публикация через deploy уже существует; самостоятельные доказательство
владения, предварительный просмотр и принятие источника ещё нужны.
Формальный GitHub fork не обязателен. Репозиторий задаёт коренные знания и главную.

Базовый баннер: фавиконка и NODE06, код для добровольного размещения владельцами
других сайтов. Обмен баннерами и webring требуют отдельной договорённости.
Поддержка — ссылка на страницу поддержки основного сайта Geno-Dice, без новой
платёжной системы. Баннер/ссылка в этом пакете не добавляются.

## Межсерверная синхронизация

Синхронизируются личные настройки: подписки, свои точки, избранное, цвет и другие
настройки профиля. На каждом сервере отдельная регистрация; связывание аккаунтов
явное и отзываемое, по разрешению пользователя. Публичный профиль открыт для
чтения, частные данные требуют отдельного ограниченного доступа.

Влияние T1, полномочия, баны, сессии, пароли и аварийные коды не переносятся.
Свои точки требуют сохранения авторства/происхождения и правил конфликтов,
удаления и ревизий: синхронизация не даёт удалённому серверу произвольное право
переписывать локальные публикации. Указатели на внешние точки не дублируют вес.
Протокол репликации, разрешения и интерфейс списка серверов остаются следующими
этапами. Ранее утверждённые границы: ENTRANCES-ROOTS-NETWORK.md.
