Этап 2. Своя страница, общая вики

Статический хостинг не обязан запускать backend. Для своей страницы можно использовать два варианта: встроить всю вики через iframe или оставить локальную карту и подключить чтение общей базы через маленький iframe-посредник. Это разные способы входа, а не разные базы. Об устройстве связей — в точке [ссылки](md://links-ru).

На выбранном сервере зарегистрируйте аккаунт, добавьте HTTPS-адрес сайта в «Мои сайты», разместите выданный node06-verification.txt и подтвердите владение. Затем возьмите iframe именно своей регистрации. У NODE06 уже есть [публичный вход](https://embed.geno-dice.com/embed/v1/s_9b7bc95affa440f08ae8265c299cc2c6/). Он относится к существующему сайту Neocities; для другого адреса нужна собственная регистрация.

Пример разметки для существующего входа NODE06:

<iframe src="https://embed.geno-dice.com/embed/v1/s_9b7bc95affa440f08ae8265c299cc2c6/" title="NODE06" width="100%" height="700" loading="lazy"></iframe>

Для локальной карты в копии репозитория настройте static/connection.json: siteId, embedOrigin и serviceOrigin. Это публичные значения. После сборки публикуется dist/. Посредник читает публичные данные со своего origin; Neocities-странице не нужен прямой запрос к чужой базе. Для полного iframe оформление задаётся темой вики: CSS родительской страницы внутрь другого origin не проходит.

Пароль вводится на доверенном сервере. В подключённой статической копии редактор может открыться поверх карты, но публикация требует подтверждения в доверенном окне. Публичный bridge не получает глобальную сессию и не превращается в API записи.
